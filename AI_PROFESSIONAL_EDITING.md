# 🎨 AI Профессиональный Монтаж

Это руководство объясняет как использовать AI для профессионального монтажа видео с автоматическим применением эффектов.

---

## 🚀 Что нового?

Теперь AI не просто вставляет медиа на таймлайн - он работает как профессиональный видеомонтажер! При использовании ключевых слов AI автоматически применяет визуальные эффекты для создания красивого результата.

### Ключевые слова для активации:

- **"красиво"** / **"профессионально"** / **"стильно"** / **"элегантно"**
- **"с эффектами"** / **"крутое"**
- **"интро"** / **"аутро"**

---

## 📖 Примеры команд

### Базовое использование (без эффектов)

```
"Вставь #3 на таймлайн"
```
Результат: Просто вставит медиа без дополнительной обработки

---

### Профессиональное использование (с эффектами)

```
"Вставь фото #3 красиво"
```

**Что сделает AI:**
- ✅ Добавит **Ken Burns эффект** (медленный зум для динамики)
- ✅ Применит **Fade In** (плавное появление)
- ✅ Применит **Fade Out** (плавное исчезновение)
- ✅ Добавит **Мягкую тень** (глубина и объем)
- ✅ Может добавить **виньетку** или **закругленные углы**

---

```
"Добавь видео #1 в начало с эффектами"
```

**Что сделает AI:**
- ✅ Вставит в начало таймлайна (позиция: 0)
- ✅ Добавит **Fade In** для плавного начала
- ✅ Применит **Zoom In** анимацию
- ✅ Может добавить дополнительные эффекты в зависимости от контекста

---

```
"Сделай профессиональное интро с картинкой #5"
```

**Что сделает AI:**
- ✅ Создаст интро-секцию
- ✅ Применит **стильную анимацию** (slide-in, zoom, fade)
- ✅ Добавит **визуальные эффекты** (тени, виньетка, размытие)
- ✅ Может предложить добавить текст или логотип

## 🎬 Доступные эффекты

### Для изображений (фото, картинки):

| Эффект | Описание | Когда применяется |
|--------|----------|-------------------|
| **Ken Burns** | Медленный зум и панорамирование | Автоматически для статичных изображений |
| **Fade In/Out** | Плавное появление/исчезновение | Интро, аутро, переходы |
| **Мягкая тень** | Drop shadow для глубины | Профессиональный стиль |
| **Закругленные углы** | Rounded corners | Современный стиль |
| **Размытый фон** | Background blur + scale | Для заполнения 16:9 |
| **Виньетка** | Затемнение краев | Художественный эффект |

### Для видео:

| Эффект | Описание | Когда применяется |
|--------|----------|-------------------|
| **Fade In/Out** | Плавное появление/исчезновение | Начало/конец клипа |
| **Zoom In** | Приближение | Динамическое начало |
| **Slide In** | Въезд слева/справа | Переходы между сценами |

### Для композиции:

| Эффект | Описание | Когда применяется |
|--------|----------|-------------------|
| **Picture-in-Picture** | Картинка поверх видео | Overlay, реакции |
| **Overlay** | Наложение с blending | Тексты, графика |
| **Center Crop** | Центрирование и кадрирование | Автоматическое выравнивание |

## 🧠 Как это работает?

### Шаг 1: AI распознает намерение

Когда вы говорите **"вставь фото красиво"**, AI понимает:
- Тип медиа: **фотография**
- Намерение: **профессиональная обработка** (ключевое слово "красиво")
- Контекст: позиция в таймлайне, длительность, соседние клипы

### Шаг 2: AI выбирает эффекты

AI использует **AISmartEffectsService** который:
1. Анализирует контекст (интро/середина/аутро, тип медиа)
2. Вызывает AI модель (Claude/OpenAI/Gemini) с промптом
3. Получает рекомендации по эффектам
4. Fallback к стандартным профессиональным эффектам если AI недоступен

**Пример AI промпта:**
```
Ты профессиональный видеомонтажер. Пользователь хочет: "вставить фото красиво"

Контекст:
- Тип медиа: фотография
- Позиция: начало ролика (интро)
- Длительность: 5.0 секунд

Выбери 2-4 эффекта для профессионального вида...
```

### Шаг 3: Применение эффектов

AI автоматически:
- Создает Effect объекты с правильными параметрами
- Добавляет их к clip перед вставкой на таймлайн
- Логирует какие эффекты были применены

## 🎯 Контекстная обработка

AI учитывает **позицию в таймлайне**:

### Интро (начало ролика, 0-5 секунд):
- Fade In обязательно
- Zoom In для динамики
- Более "энергичные" эффекты

### Середина:
- Ken Burns для фото
- Стандартные переходы
- Баланс между динамикой и стабильностью

### Аутро (конец ролика):
- Fade Out обязательно
- Виньетка для финала
- Замедление (если применимо)

## ⚙️ Настройка

### Без API ключа (Fallback режим):

Если AI провайдер недоступен, используются **стандартные профессиональные эффекты**:
- Для фото: Ken Burns + Fade In/Out + Shadow
- Для видео: Fade In/Out
- Для overlay: PiP + Shadow

### С API ключом (Умный режим):

AI анализирует контекст и выбирает оптимальные эффекты:
- Учитывает тип медиа
- Анализирует намерение пользователя
- Подбирает стиль под общий проект
- Может варьировать интенсивность эффектов

## 🚀 Best Practices

### ✅ Делайте:

1. **Используйте ключевые слова**
   - "красиво", "профессионально", "стильно"
   - AI сразу поймет что нужны эффекты

2. **Указывайте контекст**
   - "сделай интро", "завершающий кадр"
   - AI подберет эффекты под позицию

3. **Комбинируйте команды**
   - "Вставь #1, #2, #3 как слайдшоу с эффектами"
   - AI обработает все клипы согласованно

### ❌ Не делайте:

1. **Не смешивайте простые и профессиональные команды**
   - Плохо: "Вставь #1, а #2 красиво"
   - Хорошо: "Вставь #1 и #2 профессионально"

2. **Не перегружайте эффектами**
   - AI уже подберет оптимальное количество
   - Если нужно больше - скажите явно

3. **Не используйте противоречивые стили**
   - Плохо: "стильно и минималистично с кучей эффектов"
   - Хорошо: "элегантно и минималистично"

## 🔧 Технические детали

### Файлы:

- **`AISmartEffectsService.ts`** - Сервис умных эффектов
- **`AICommandExecutor.ts`** - Выполнение команд с эффектами
- **`AIEditorService.ts`** - Парсинг команд пользователя

### Типы:

```typescript
interface ProcessingContext {
  mediaType: 'video' | 'image' | 'audio';
  userIntent: string;
  clipDuration: number;
  position: 'intro' | 'middle' | 'outro' | 'overlay';
}

interface SmartEffectSuggestion {
  type: 'visual' | 'animation' | 'transform' | 'composite';
  effects: Effect[];
  reasoning: string;
}
```

## ❓ FAQ

**Q: Как отключить автоматические эффекты?**
A: Просто не используйте ключевые слова. Команда "Вставь #3" вставит без эффектов.

**Q: Можно ли изменить примененные эффекты?**
A: Да! Эффекты добавляются как обычные Effect объекты, их можно редактировать в панели Inspector.

**Q: Какой AI провайдер лучше для эффектов?**
A: Claude 3.5 Sonnet показывает лучшее понимание контекста монтажа. GPT-4 тоже хорош. Gemini работает для базовых случаев.

**Q: Работает ли без интернета?**
A: Да! Есть fallback на стандартные профессиональные эффекты если AI недоступен.

**Q: Сколько это стоит?**
A: ~$0.01-0.05 за запрос к AI. Большинство команд используют fallback и бесплатны.
