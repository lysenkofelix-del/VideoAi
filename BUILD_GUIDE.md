# 🏗️ Build Guide - Создание .exe файла

## Быстрый старт

### Для Windows

```bash
# 1. Установить зависимости
npm install

# 2. Собрать .exe файл
npm run dist:win
```

Готовый .exe будет в папке `release/`

---

## 📦 Что будет создано

После сборки вы получите **2 файла**:

1. **AI Video Editor PRO-0.1.0-Setup.exe** - Установщик (рекомендуется)
   - Установка в Program Files
   - Ярлыки на рабочем столе и в меню Пуск
   - Удобное обновление

2. **AI Video Editor PRO-0.1.0-Portable.exe** - Портативная версия
   - Запуск без установки
   - Можно запускать с флешки
   - Все настройки сохраняются локально

## 🤖 Рекомендуемый AI сервис

### Anthropic Claude API ⭐ (ЛУЧШИЙ ВЫБОР)

**Почему Claude:**
- ✅ **Отличное понимание** естественного языка
- ✅ **Большой контекст** - 200,000 токенов (можно передать всю информацию о проекте)
- ✅ **Точность** - лучше всех выполняет структурированные команды
- ✅ **Цена** - $3 за 1M входных токенов, $15 за 1M выходных
- ✅ **Модель** - Claude 3.5 Sonnet (самая мощная)

**Как получить:**
1. Перейти на https://console.anthropic.com/
2. Зарегистрироваться (бесплатно)
3. Получить $5 бесплатных кредитов
4. Создать API ключ в разделе "API Keys"
5. Скопировать ключ (начинается с `sk-ant-api...`)

**Стоимость использования:**
- ~100 команд = $0.10-0.30
- Для обычного использования: $1-3 в месяц
- Бесплатные $5 хватит на ~500-1000 команд

### Альтернативы (не рекомендуется):

**OpenAI GPT-4:**
- ❌ Дороже ($10/$30 за 1M токенов)
- ❌ Меньший контекст (128K)
- ❌ Хуже понимает структурированные команды
- ✅ Но тоже работает

**Google Gemini:**
- ✅ Есть бесплатный tier
- ❌ Менее точный для команд редактирования
- ❌ Меньше контекста

## 💡 Работа БЕЗ AI ключа

Редактор **полностью работает без AI!**

**Что доступно без AI:**
- ✅ Весь функционал Premiere Pro
- ✅ 50+ эффектов
- ✅ Lumetri Color
- ✅ Timeline, Preview, Inspector
- ✅ Essential Graphics
- ✅ Импорт/Экспорт
- ✅ Все ручные инструменты

**Что НЕ работает без AI:**
- ❌ AI-ассистент (чат)
- ❌ AI-эффекты (Background Remove, Upscale и т.д.)
- ❌ Автоматический анализ видео
- ❌ Генерация контента

**Вывод:** Можно спокойно работать без AI, а подключить его позже в настройках!

## 🔧 Детальная сборка

### Требования

- **Node.js** 18+ ([скачать](https://nodejs.org/))
- **npm** или **yarn**
- **Git** (опционально)
- **Windows** 10/11 (для .exe)

### Шаг 1: Клонировать репозиторий

```bash
git clone https://github.com/your-username/VideoAi.git
cd VideoAi
```

### Шаг 2: Установить зависимости

```bash
npm install
```

Это установит:
- Electron (desktop framework)
- React + TypeScript
- FFmpeg binaries
- Все необходимые библиотеки

### Шаг 3: Собрать приложение

**Вариант A: Только .exe для Windows**
```bash
npm run dist:win
```

**Вариант B: Для всех платформ**
```bash
npm run dist        # Windows + Mac + Linux
```

**Вариант C: Конкретная платформа**
```bash
npm run dist:win    # Windows
npm run dist:mac    # macOS
npm run dist:linux  # Linux
```

### Шаг 4: Найти готовый файл

```
📁 VideoAi/
└── 📁 release/
    ├── AI Video Editor PRO-0.1.0-Setup.exe      ← Установщик
    ├── AI Video Editor PRO-0.1.0-Portable.exe   ← Портативная версия
    └── latest.yml                                ← Для авто-обновлений
```

## 📝 Настройки сборки

### Изменить версию

В `package.json`:
```json
{
  "version": "0.2.0"  // <- Изменить здесь
}
```

### Изменить иконку

1. Создать иконку `icon.ico` (256x256)
2. Положить в `assets/icons/icon.ico`
3. Пересобрать

### Настроить установщик

В `package.json` → `build.nsis`:
```json
{
  "oneClick": false,                    // Пользовательская установка
  "allowToChangeInstallationDirectory": true,  // Выбор папки
  "createDesktopShortcut": true,       // Ярлык на рабочем столе
  "createStartMenuShortcut": true      // Ярлык в меню Пуск
}
```

## 🔐 Безопасность API ключа

**Где хранится:**
- `localStorage` браузера Electron
- Только на вашем компьютере
- Никуда не передается кроме API Anthropic

**Как изменить:**
1. Открыть Settings (⚙️ в правом верхнем углу)
2. Вкладка "AI"
3. Ввести новый ключ
4. Сохранить

**Как удалить:**
1. Settings → AI
2. Очистить поле API Key
3. Сохранить
4. AI отключится, остальное работает

## ❓ FAQ

### Q: Нужен ли интернет?
**A:** Только для AI-функций. Остальное работает оффлайн.

### Q: Сколько стоит использование?
**A:** Редактор бесплатный. AI ключ стоит ~$1-3/месяц при обычном использовании.

### Q: Можно ли использовать свой AI?
**A:** Да, код открыт. Можно подключить любую AI API в `src/renderer/services/ai/AIEditorService.ts`

### Q: Работает ли на старых ПК?
**A:** Требования:
- Windows 10+
- 4GB RAM (8GB рекомендуется)
- 500MB свободного места
- GPU с поддержкой OpenGL (для preview)

### Q: Как обновить?
**A:** Скачать новую версию и установить поверх старой. Настройки сохранятся.
