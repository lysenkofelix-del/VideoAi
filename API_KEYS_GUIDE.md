## Claude (Anthropic)

### ✅ Почему Claude?
- **Лучшее качество** для творческих задач
- Понимание контекста видеомонтажа
- Точное выполнение команд
- Поддержка длинных запросов

### 💰 Стоимость
- **Pay-as-you-go**: $3 за 1M входных токенов, $15 за 1M выходных токенов (Claude 3.5 Sonnet)
- **Нет ежемесячной платы** - платите только за использование
- Первые $5 бесплатно для новых пользователей

### 📝 Как получить API ключ:

#### Шаг 1: Создайте аккаунт
1. Перейдите на [console.anthropic.com](https://console.anthropic.com/)
2. Нажмите **"Sign Up"** (Зарегистрироваться)
3. Введите email и создайте пароль
4. Подтвердите email

#### Шаг 2: Добавьте платежные данные
1. В консоли перейдите в **Settings → Billing**
2. Нажмите **"Add payment method"**
3. Введите данные карты (Visa, Mastercard, American Express)
4. Установите лимит расходов (рекомендуется $10-20 для начала)

#### Шаг 3: Создайте API ключ
1. Перейдите в **Settings → API Keys**
2. Нажмите **"Create Key"**
3. Дайте название ключу (например: "VideoAI Editor")
4. Скопируйте ключ - **он больше не будет показан!**
5. Формат ключа: `sk-ant-api03-xxxxx...`

#### Шаг 4: Добавьте в приложение
1. Откройте AI Video Editor
2. Перейдите в **Настройки** (⚙️)
3. Вставьте ключ в поле **"Claude API Key"**
4. Нажмите **"Сохранить"**

### 🌍 Доступность
- **Доступно**: США, Великобритания, Европа, Канада, Австралия
- **Недоступно**: Россия, Китай, некоторые другие страны
- **Решение**: Используйте VPN или виртуальную карту другой страны

## OpenAI (GPT)

### ✅ Почему OpenAI?
- Широкая доступность
- GPT-4o - быстрая и мощная модель
- Большое комьюнити
- Хорошая документация

### 💰 Стоимость
- **GPT-4o**: $2.50 за 1M входных токенов, $10 за 1M выходных токенов
- **GPT-4 Turbo**: $10 за 1M входных токенов, $30 за 1M выходных токенов
- Первые $5 бесплатно для новых аккаунтов

### 📝 Как получить API ключ:

#### Шаг 1: Создайте аккаунт
1. Перейдите на [platform.openai.com](https://platform.openai.com/signup)
2. Зарегистрируйтесь через email или Google/Microsoft
3. Подтвердите email
4. Пройдите верификацию телефона

#### Шаг 2: Добавьте баланс
1. Перейдите в **Settings → Billing**
2. Нажмите **"Add payment method"**
3. Введите данные карты
4. Пополните баланс (минимум $5)

#### Шаг 3: Создайте API ключ
1. Перейдите в **API Keys**
2. Нажмите **"+ Create new secret key"**
3. Дайте название (например: "VideoAI")
4. Выберите права доступа (рекомендуется "All")
5. Скопируйте ключ - формат: `sk-proj-xxxxx...` или `sk-xxxxx...`

#### Шаг 4: Добавьте в приложение
1. Откройте AI Video Editor
2. Настройки → **"OpenAI API Key"**
3. Вставьте ключ и сохраните

### 🌍 Доступность
- **Доступно**: Почти все страны
- **Недоступно**: Россия (с марта 2024), Китай, Иран
- **Решение**: VPN + виртуальная карта

## Google Gemini

### ✅ Почему Gemini?
- **Бесплатный tier** - до 60 запросов в минуту
- Мультимодальность (текст + изображения)
- Быстрая работа
- Хорошая интеграция с Google сервисами

### 💰 Стоимость
- **Бесплатный tier**:
  - 15 запросов в минуту
  - 1500 запросов в день
  - Достаточно для большинства пользователей
- **Pay-as-you-go**:
  - Gemini 1.5 Flash: $0.075 за 1M токенов (вход), $0.30 за 1M токенов (выход)
  - Gemini 1.5 Pro: $1.25 за 1M токенов (вход), $5 за 1M токенов (выход)

### 📝 Как получить API ключ:

#### Шаг 1: Создайте аккаунт Google
1. Если у вас есть Gmail - переходите к Шагу 2
2. Иначе создайте аккаунт на [accounts.google.com](https://accounts.google.com/)

#### Шаг 2: Перейдите в Google AI Studio
1. Откройте [aistudio.google.com](https://aistudio.google.com/)
2. Войдите с вашим Google аккаунтом
3. Примите условия использования

#### Шаг 3: Создайте API ключ
1. Нажмите **"Get API Key"** в левом меню
2. Нажмите **"Create API Key"**
3. Выберите существующий Google Cloud проект или создайте новый
4. Скопируйте ключ - формат: `AIzaSy...`

#### Шаг 4: (Опционально) Настройте биллинг
1. Если нужно больше лимитов, перейдите в [console.cloud.google.com](https://console.cloud.google.com/)
2. Выберите проект → Billing → Add payment method

#### Шаг 5: Добавьте в приложение
1. AI Video Editor → Настройки
2. Вставьте ключ в **"Google Gemini API Key"**

### 🌍 Доступность
- **Доступно**: Большинство стран
- **Ограничения**: Некоторые функции недоступны в ЕС

## Пользовательские API (Custom)

### ✅ Когда использовать?
- Вы хостите свою LLM модель
- Используете прокси для обхода ограничений
- Корпоративный AI endpoint
- Альтернативные провайдеры (Cohere, Together.ai, Replicate)

### 📝 Настройка:

#### Для совместимых с OpenAI API:
1. В настройках выберите **"Custom OpenAI-compatible"**
2. Укажите:
   - **Base URL**: `https://your-api.com/v1`
   - **API Key**: Ваш ключ
   - **Model Name**: Название модели (например: `gpt-4`, `claude-3-opus`)

#### Примеры провайдеров:

**Together.ai**
- URL: `https://api.together.xyz/v1`
- Модели: `meta-llama/Llama-3-70b-chat-hf`, `mistralai/Mixtral-8x7B-Instruct-v0.1`
- Стоимость: От $0.2 за 1M токенов

**Groq** (очень быстро!)
- URL: `https://api.groq.com/openai/v1`
- Модели: `llama-3.1-70b-versatile`, `mixtral-8x7b-32768`
- Бесплатный tier с ограничениями

**OpenRouter** (доступ ко всем моделям)
- URL: `https://openrouter.ai/api/v1`
- Модели: Claude, GPT, Llama, Gemini и др.
- Платите только за использование

## Безопасность API ключей

### ⚠️ Важные правила:

1. **Никогда не делитесь ключами**
   - Не публикуйте в соцсетях, GitHub, форумах
   - Не отправляйте по email или мессенджерам
   - Не храните в открытом виде

2. **Используйте лимиты**
   - Установите месячный лимит расходов ($10-50)
   - Это защитит от случайной перерасходы

3. **Регулярно меняйте ключи**
   - Обновляйте каждые 3-6 месяцев
   - Сразу удаляйте скомпрометированные ключи

4. **Мониторьте использование**
   - Проверяйте статистику в консоли провайдера
   - Настройте уведомления о превышении лимита

### 🔒 Как приложение защищает ключи:

- ✅ Ключи хранятся локально на вашем компьютере
- ✅ Используется шифрование при хранении
- ✅ Ключи НЕ передаются на сторонние серверы
- ✅ Все API запросы идут напрямую к провайдеру

## ❓ Часто задаваемые вопросы

### Какой провайдер лучше для начинающих?
**Google Gemini** - есть бесплатный tier, не нужна карта для старта.

### Сколько стоит в месяц?
Зависит от использования. В среднем:
- Легкое использование (10-20 команд/день): **$1-3/месяц**
- Среднее использование (50-100 команд/день): **$5-15/месяц**
- Интенсивное использование: **$20-50/месяц**

### Можно ли использовать несколько ключей?
Да! Приложение поддерживает несколько провайдеров одновременно. Вы можете переключаться между ними в настройках.

### Что делать если ключ не работает?
1. Проверьте формат ключа
2. Убедитесь что добавлены платежные данные
3. Проверьте баланс аккаунта
4. Попробуйте создать новый ключ
5. Проверьте доступность API в вашей стране

### Могу ли я использовать VPN?
Да, но:
- Некоторые провайдеры блокируют известные VPN IP
- Используйте качественные VPN сервисы
- Лучше использовать виртуальные карты страны провайдера
